Información útil

¿Cómo uso un lector de pantalla?

Podés usar el lector que ya trae tu dispositivo:

  • Windows: Narrador (Windows + Ctrl + Enter) o NVDA.
  • Android: TalkBack, desde Ajustes → Accesibilidad.
  • iPhone: VoiceOver, desde Ajustes → Accesibilidad.

Los títulos permiten recorrer la página con tecnologías de apoyo. No necesitás activar nada especial dentro de Bermejo.

Privacidad y uso de la IA

Podés trabajar con textos y documentos en tu navegador, sin crear una cuenta. La web no guarda tus materiales como archivos personales.

Algunas funciones necesitan conexión para descargar herramientas o pictogramas. Cuando elegís utilizar IA, revisá el aviso de cada herramienta antes de autorizar el envío de información. Evitá incluir datos personales.
